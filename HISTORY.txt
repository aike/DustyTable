DustyTable(旧名 PhysVinyl) 開発の経緯 (2026-11-24 時点、24. まで)
========================================

■ 目的
レコード盤のノイズを物理モデリングで鳴らす VST3 エフェクト(JUCE 8.0.4)。
入力音にノイズを加算する。回転数は 33 / 45(表記は「33」。内部は 33 1/3 で計算)。
方針:新しい音もすべて物理モデリングの範囲で作る。ユーザーが頼んでいない機能は、実装前に相談する。

■ 経緯
1. 最初の依頼:盤面を擦るノイズ、ホコリ(プチプチ)、キズ(ボツッ)。
   相談の結果、次のとおり決めた。
   - 追加する:静電気(パチパチ)、針位置の自動進行、カスタムGUI
   - 入れない:内周歪み
2. 静電気をホコリと聞き分けられるように、「細かく密なチリチリ」に変更した。
   - 帯電した電荷が雪崩的に放電するモデルにした。
   - 放電パルスは、カートリッジのLC共振(16kHz、Q3)で鳴らす。
3. ユーザーの判断で、盤面を擦るノイズ(surface noise)の処理とパラメータを全部削除した。
4. 「STATIC」の表記を「STATIC ELECTRICITY」に変更した。
5. キズの低音を増やした。
   - 削られた盤材の盛り上がり(Pile-up)のモデルを追加し、Pile-up パラメータを設けた。
   - 約 1.5mm で効果が頭打ちになる。
6. アームの上げ下げを検討し、実装した(1回目)。
   - カートリッジを通る音:接地、離脱
   - 空気中の音(カートリッジを通らない):キューレバー、リフター、アームレスト
   - 操作方法:Arm パラメータ(オートメーション可)とGUIのボタン。DAWの再生・停止とは連動しない。
   - 原音:針が溝に接している間だけ鳴らす(案A)。
7. アームの上げ下げを改訂した(2回目)。
   - ユーザーの指示
     ・空気中の音を「低く」する。音量ではなく音の高さのこと。
     ・アームをモーターで動かす。リフターの上げ下げもモーターのカムで動かす。
     ・ターンテーブルを回すモーターの音は不要。
   - 変更内容
     ・キューレバーを削除した。
     ・1つのDCモーター(1.5V駆動)が、ウォームギア 1:30 と平歯車 1:6.2 を介してカムを回す。
       カム1サイクル(約3秒)で「リフターを上げる → アームを振る → リフターを下げる」を行う。
     ・正転でダウン、逆転でアップ。両端はリミットスイッチで止まる。
     ・リフターが下がる速さは、オイルダンパー(Cue damping)で制限される。
     ・アームレストのクランプは手で操作するまま残した。
   - 音の高さを下げるために、次の点を直した。
     ・アームパイプ、クランプ、支柱について、先端に付く質量を固有振動の計算に入れた。
     ・クランプが当たる面を、ゴムとPVCにした。
     ・支柱の接触力が、そのままキャビネットに伝わるようにした。
     この結果、音の中心は 2〜4kHz から 0.25〜1kHz に下がった。
   - モーター音の音源
     ・コミュテータによるトルクの脈動
     ・ブラシの摩擦
     ・ロータのアンバランス
     ・ギアの噛み合い
     これらがモーターのケース、ギアボックスのカバー、キャビネットを鳴らす。
     モーターはゴムブッシュで固定している想定。
   - 音量の倍率を合わせ直した:pascalToFullScale を 2.8 にし、クランプを閉める音が約 -20dBFS になるようにした。

8. 実機の動画(reference/ターンテーブル.mp4、ベルトドライブのオートマチック機)を分析して、機械音を作り直した(2026-11-23)。
   - ユーザーの依頼:STARTボタン、アームが移動するときの機構の音、STOPボタン、アームがアームレストに当たる音を、
     「そのままではなく、これを想起させる音」として物理モデリングで作る。
   - 動画の分析結果(2回の上げ下げで同じパターンだった)
     ・ボタン:押すと約50msで「カチッ」(1.4〜2.4kHzが中心、600〜800Hzもある)。約0.6秒後に離す音(少し小さい)。
     ・STARTの約6.4秒後に機構のクリック(2kHz付近)。アームが動く間、ギアの「ジー」が鳴る。
       ギアの音は約70Hz間隔の倍音(290〜560Hz)で、周りの雑音より10〜15dB大きい。
     ・下ろすときの「コトッ」:400〜700Hzが中心。約100msの間に何回か当たる。
     ・アームレストに当たる「カツン」:300〜900Hzと1.7〜2.5kHz。約30ms後にもう一度当たり、150msでほぼ消える。
     ・衝突音どうしはほぼ同じ大きさ。ギアの音はそれより25〜30dB小さい。
   - 変更内容
     ・START/STOPボタンを追加した。指先の柔らかさ、タクトスイッチのドームの座屈、キーが底と縁に当たる動きを計算する。
       クランプは手で操作するまま残し、ダウンは「クランプを外す → STARTを押す」の順にした。
     ・カムを一方向回転にした。半回転ごとに止まり、前半がダウン、後半がアップ。
       これに伴い、途中で逆の操作をしてもモーターは逆転せず、次の停止位置まで回る。平歯車を 8:88 にした(半回転は約3.2秒)。
     ・リミットスイッチの板ばねがカムの切り欠きに落ちる音と、切り欠きから出る音を追加した。
     ・リフターを下げるときに、カムの従動レバーが段差から落ちて当たる「コトッ」を追加した。
     ・アームはすべりクラッチで振られ、戻りではアームレストのストッパーに当たって弾む「カツン」を追加した。
     ・ギアの歯ごとの誤差と、カム表面の微小な凹凸(0.05µm)を入れた。
     ・板のモード計算を直した。モードの数を増やし、加振点でのモード形状を考慮する。キャビネットは15mmにした。
       これで、実機と同じように 300〜900Hz に多くの共振が並ぶ。全体の倍率は pascalToFullScale = 0.4 に合わせ直した
       (クランプを閉める音は以前と同じ約 -21dBFS)。
     ・部品の寸法・素材・速度は、各音のスペクトルと相対的な音量が実機に近くなるように選んだ。

9. 機械音を調整した(2026-11-23、聴いたうえでのユーザーの指示)。
   - リミットスイッチが切り欠きに落ちる音(停止位置に着いたときの高い音)を、低く小さくした。
     ・スイッチの作動部の先端をエラストマー(E* 約20MPa)にし、当たる速さを下げ、ギアボックスのカバーへの伝わりを減らした。
     ・押し付け力を支えていたものが一瞬で外れるときの段差の力が「チッ」の原因だったので、3msかけて外れるようにした
       (アームのストッパーにも同じ扱いを適用)。
     ・-29dBFS・1.3kHz中心 → 約 -37dBFS・200〜600Hz中心。
   - 機械音を毎回少しずつ変えるようにした。
     ・操作のたびに、関係する部品の共振周波数を約±35セント、加振の強さを約±2dBばらつかせる
       (当たる位置や締まり具合の違いという想定)。従動レバーは、カムの段差から離れるたびに変える。
     ・ボタンのドームの硬さ(±15%)、指の速さ、押している時間、衝突の速度、モーターの電圧(±4%)も毎回変わる。
     ・4回の上げ下げで確認:同じ音でも、ピークが2〜5dB、主な共振が約4%違う。
   - GUIのボタンをSTARTとSTOPの2つにした。パラメータ名は「Start (on) / Stop (off)」(IDは arm のまま。保存済みのプロジェクトはそのまま開ける)。
   - クランプは現状のまま(手で操作)。
   - STARTを押してから機構が動き出すまで1秒待つようにした(STOPはすぐ動く)。
   - 書き出しツールに arm_cycles(40秒で4回の上げ下げ)を追加した。

10. さらに調整した(2026-11-23、ユーザーの指示)。
   - START/STOPボタンの音を小さくした(約 -20dBFS → 約 -27dBFS)。ドームを柔らかくし(ピーク 0.5N)、キー・パネル・キャビネットへの伝わりを減らした。
   - 接地の「ボツッ」(カートリッジ経由、低く大きい音)を追加した。
     ・リフターのオイルダンパーは盤面の手前 0.6〜1mm(毎回ランダム)で効かなくなり、アームはそこから自重で落ちて針が溝に当たる。
     ・接地は約 -25dBFS → 約 -6dBFS。約9Hz(アームの共振)が主で、可聴域は 30〜100Hz が中心、約0.25秒で減衰。

     CMakeのターゲットとオプション(DUSTYTABLE_BUILD_PLUGIN、DUSTYTABLE_JUCE_PATH)、名前空間(dustytable)、クラス名、

   - 変えていないもの
     ・プラグインのID(PLUGIN_MANUFACTURER_CODE Pvnl、PLUGIN_CODE Pvn1):ホストに保存済みのプロジェクトが引き続きこのプラグインを見つけられるようにするため。
   - 旧名で保存された状態(タグ PhysVinyl)も読み込める。
   - その後、プロジェクトのフォルダ名も D:\src\physvinyl から D:\src\DustyTable に変更した。

12. 盤面のツール(ホコリ・釘・消しゴム)を追加した(2026-11-23)。
   - ユーザーの依頼:お絵描きツールのように、ホコリとキズを盤面に自由に付けたり消したりできるようにする。
     UIから SCRATCH の Count・Length・Layout と DUST の Density を削除する。確認事項13点はすべて推奨案で決定。
   - 盤面の左上にツールアイコンを3つ置いた。選んでいるアイコンをもう一度押すと解除される。カーソルはツールの形になる。
     ・ホコリ:盤面を押している間、ホコリ(Dust Density)が増える。押した時間の合計が約5秒で最大(60/m)。
       盤面全体が黒からまだらなグレーになる。まだら模様は見た目だけで、音は均一なホコリとして計算する。
     ・釘:押して離すと、離した位置を通るキズができる。向きは放射状で、ねじれと弓なりの曲がりが毎回ランダムに付く。
       長さは押していた時間に比例し、最短約2mm、約2秒で最大(録音帯の幅の2/3)。押している間は、できるキズをオレンジ色で表示する。
       盤の外で離すとキズはできない。最大32本で、超えると一番古いキズが消える。
     ・消しゴム:キズから約8px以内のクリックで一番近いキズを消す。それ以外の盤面では、クリックでホコリが最大量の約5%減り、
       押し続けると(0.3秒以降)ホコリツールと同じ速さで減る。
   - パネル右下に、ツールの使い方の説明を加えた。STATIC ELECTRICITY の見出しが省略されないように、つまみの並びを詰めた。
   - パラメータ
     ・scratchCount、scratchLength、scratchSeed を削除した。
     ・dustDensity はUIから外したが、パラメータとしては残した(保存済みの値が読み込め、オートメーションも使える)。ツールはこの値を変える。
   - キズのデータ
     ・プロジェクトの状態(SCRATCHES 要素)に保存する。録音帯の中での相対位置(0〜1)で持つので、盤サイズを変えても同じ配置のまま。
     ・Depth と Pile-up のつまみは、従来どおり全部のキズにまとめて効く。1本ごとの幅や深さの違いは、キズを作るときのランダムな係数で持つ。
     ・古いプロジェクト(SCRATCHES がなく scratchCount がある)は、旧設定から同じ配置のキズを作って取り込む。
       従来の配置で書き出した音と新しい音の差は、最大でもピークより -220dB 以下(計算の丸め誤差のみ)。
     ・エディタと音声スレッドの受け渡しはスピンロックで行い、音声スレッドは待たない(取れないときは次のブロックで反映)。
   - DustyTableUiCheck(画面を出さずにツールを操作し、スナップショットを保存するツール)を追加した。
     書き出しツールにも scratch_cut(手で付けた長さの違う3本のキズ)を追加した。

13. ツールの使い勝手と、ターンテーブルの回転を直した(2026-11-23、ユーザーの指示)。
   - ユーザーの指摘:意図した場所にキズを付けたり消したりするのが難しい。ツールは盤が回っていても止まっていても使えること。
     STOPでアームを戻したら盤の回転を止めること。右下の RECORD TOOLS の説明は不要。
   - 原因:盤の角度は音声ブロックごとにしか更新されず、ツールは描画とは違う瞬間の角度で位置を計算していた。
     また、33回転では外周のキズが1秒に約700px動くので、8pxの範囲でクリックするのはほぼ不可能だった。
   - ツール
     ・画面の毎フレームで、音声スレッドが報告した角度をその時刻まで進めた角度(framePhase)を使って描き、ツールも同じ角度で位置を決める。
       回転も滑らかになった。
     ・消しゴム:ポインタから12px以内を直近0.4秒のうちに通ったキズのうち、最後に通ったものを対象にし、オレンジ色で予告表示する。
       フレームの間に通り過ぎた場合も数える。回っている盤では、キズがポインタの下を通った直後(0.25秒後)のクリックで消えることを確認。
     ・釘:離した瞬間に画面で見えている位置にキズができる(回っている盤でも、離した点をキズが通ることを確認)。
       手で付けるキズのねじれと曲がりを少し弱めた(ねじれ ±0.15rad、曲がり ±0.08rad。長いキズが斜めに寝すぎていたため)。
   - ターンテーブルの回転
     ・STARTボタンでプラッターのモーターが入り、約0.8秒で定速になる(アームが動き出すまでの1秒の待ちの間)。
     ・STOP後、アームがアームレストに戻ってカムのモーターが止まると、プラッターのモーターが切れ、約2.5秒かけて止まる(ブレーキ)。
       STARTから1秒以内にSTOPした場合は、すぐに止まり始める。
     ・定速のときは従来どおりホストの再生位置から盤の角度を決める。止まっていた分の角度はずれとして保持する。
       状態を読み込んだときは、アームの状態に合わせて回っているか止まっているかから始まる。
     ・盤の線速度の表示も回転に合わせた。プラッターのモーター音は従来どおり入れていない。
     ・アームの上げ下げの書き出し(arm_down など)は変更前とビット単位で一致。書き出しツールにプラッターの始動・停止の時刻を表示するようにした。
       (ダウン:1.07秒 始動、1.87秒 定速。アップ:4.03秒 減速開始、6.53秒 停止)
   - 右下の RECORD TOOLS の説明を削除した(ツールのアイコンにはツールチップが残っている)。
   - DustyTableUiCheck を、盤が回っている場合と止まっている場合の両方を自動で確認するようにした(13項目、すべて合格)。

14. 針が内側へ進むようにし、録音帯の終わりで自動STOPするようにした(2026-11-23、ユーザーの指示)。
   - ユーザーの依頼:再生中は本物のようにアームが少しずつ内側に動く。一番内側に達したら自動でSTOP。有効・無効の切り替えUIはなく常に有効。
     Position はアームが下りる位置として残し、現在の位置も数字で表示する(名前はわかりやすく考える)。それ以外の確認事項は推奨案で決定。
   - これまで:針の位置は「Position + ホストの再生時刻 ÷ Side」で決まり、内周に達すると外周に戻っていた。
   - 変更内容
     ・Auto advance をUIとパラメータから削除した(常に有効)。古いプロジェクトに残っている auto パラメータは読み込み時に捨てる。
     ・Position つまみは「Drop point」(パラメータ名 Drop Point、IDは position のまま)にした。STARTでアームがこの位置に下りる。
       英語の「drop the needle(針を落とす)」から取った。
     ・現在の針の位置は、盤面の下の情報行の先頭に「Stylus 37.25 %」の形で表示する(Drop point と同じ % 表記)。
     ・針は、溝に乗っていて盤が回っている間だけ、Side の長さで録音帯の外周から内周まで進む(盤の回転速度に比例)。
       ホストの再生・停止とは関係ない。着地するまでは Drop point に従い、着地後はつまみを動かしても針は動かない。
       アームがアームレストに戻ると、針の位置は Drop point に戻る。
     ・録音帯の終わり(100%)に達すると、STOPと同じ動作をする。プロセッサが Start/Stop パラメータを Stop に切り替え、
       ホストとUIに伝える(音声スレッドからではなく、メッセージスレッドで切り替える)。パラメータが Stop になるまでは、
       Start のままでも再び下りない。
     ・プロジェクトに針の位置(stylusPosition)を保存し、アームが盤の上にある状態なら、開いたときにその位置から再開する。
   - 確認
     ・書き出しツールに end_of_side(1分の面、Drop point 98%)を追加:1.2秒で終わりに達し、1.82秒で離脱、7.22秒で盤が停止。Start のままでも再び下りない。
     ・アームの上げ下げの音は変更前とビット単位で一致。ホコリ・キズの書き出しは、針の位置の計算方法が変わったぶんだけ違う(ピークより -150dB 以下)。
     ・DustyTableUiCheck に、プロセッサに音声ブロックを流す確認を追加(針が進む、終わりで Stop に切り替わる、アームが戻り盤が止まる、保存した位置から再開)。

15. 針の切り替えをイラスト付きのスイッチにし、Standalone のアプリアイコンを作った(2026-11-23、ユーザーの指示)。
   - ユーザーの指摘:Conical/Elliptical の切り替え(コンボボックス)が分かりにくい。
   - コンボボックスを2つ並びのスイッチ(StylusSwitch)に置き換えた。各側に、溝を上から見た図と針先の接触面を描く。
     Conical は溝の幅いっぱいの円、Elliptical は溝の方向に細い楕円。選んでいる側はオレンジ色の枠と塗り。
     クリックした側が選ばれ、オートメーションにも追従する。ツールチップで針先の寸法を説明する。パラメータ(stylus)は変更なし。
   - アプリアイコン:レコード盤(赤いラベル、ホコリ)とオレンジ色のトーンアーム。Resources/icon_big.png(1024px)と、
     小さいサイズ用に溝やホコリを減らした Resources/icon_small.png を Tools/make_icon.py(Pillow)で描いた。
     juce_add_plugin の ICON_BIG / ICON_SMALL に指定し、ビルド時に icon.ico(16/32/48/256px)が実行ファイルに埋め込まれる。
   - DustyTableUiCheck にスイッチの確認(既定は Conical、左右のクリックで切り替わる、パラメータに追従)を追加した。すべて合格。

16. 針のスイッチのイラストを変え、釘のキズを直線にした(2026-11-23、ユーザーの指示)。
   - 針のスイッチ:高級感のある落ち着いたイラストにした。溝は細い線で描いて両端を薄くし、針先は宝石のような
     グラデーションに稜線とハイライトを入れた。選んでいる側はシャンパンゴールド、選んでいない側はピューター(灰色)で、
     オレンジ色の塗りはやめて細い金色の枠にした。
   - 釘のキズ:曲線(ねじれ・弓なり)をやめて直線にした。向きは放射方向から ±0.2rad の範囲でランダム。
     キズは盤の中心からの距離 lineOffset の直線として計算する(Scratch::angleAt)。プロジェクトには tilt として保存する。
     以前に保存したキズ(twist・bend を持つもの)と、旧形式のプロジェクトから取り込むキズは、従来どおりの形のまま。
     乱数の使い方は以前と同じにしたので、幅・深さなどの形の係数は変わらない。

17. その場でアームを上げ下げする UP/DOWN ボタンを追加した(2026-11-23、ユーザーの指示)。
   - ユーザーの依頼:START/STOP 以外に、その場でアームを上げ下げするボタン。アームが上がっているときに Drop point を動かすと
     その位置までアームが動く。アームが下りているときに Drop point を動かしてから上げると、上がりきったあとでゆっくり Drop point まで動く。
     ボタンは UP と DOWN の2つではなく UP/DOWN の1つで、ボタンは状態を持たない(アームの状態はアーム側が持つ)。それ以外は推奨案で決定。
   - 機構(ArmSequencer)
     ・キュー用カム:アームのカムと同じ型のモーター、ウォーム 1:30、平歯車 10:34。半回転(約1.0秒)で上げ、次の半回転で下げる。
       滑らかなカム面(段差なし)で、同じリフターの棒を押し上げる(棒の高さは2つのカムのレバーの高い方)。下りはオイルダンパー(Cue damping)の速さで、最後は自重で落ちる。
       一方向にだけ回り、半回転ごとにリミットスイッチで止まる。途中で押し直すと止まる位置が変わる(アームのカムと同じ)。
       減速比が小さく、ブレーキ後に惰性で回る量が大きいので、切り欠きを広くした(抜ける位置 0.06。アームのカムは 0.015)。
       狭いままだと停止後に切り欠きを乗り越えて「切り欠きから出る」音(約 -24dBFS)が鳴っていた。
     ・アームの横移動:同じ型のモーター、ウォーム 1:40 と平歯車(最初の段は 8:48、全体で 1:230)で、すべりクラッチを介してアームの軸を回す。
       針先で約 8.3mm/秒(逆方向は約 9mm/秒。電圧のばらつきによる)。キューがアームを上げきっている間だけ動く。
       Drop point との差が 0.2mm を超えると動き出し、ブレーキ後の惰性(速度 × 0.05秒)を見込んで手前で止める。止まる位置の誤差は約 0.04mm。
     ・UP/DOWN:アームが盤の上にある(STARTが有効な)ときだけ働き、押すたびにキューの上げ・下げを切り替える。
       START でアームが下りている途中なら、下りきってから上げる。STOP(録音帯の終わりの自動STOPを含む)でキューは下がる側に戻る。
   - 音:3つのモーターはそれぞれ自分のギアの歯の誤差とゴムブッシュのフィルターを持ち、同じモーター・ギアボックス・キャビネットを鳴らす。
     キュー用カムのリミットスイッチは、アームのカムと同じスイッチの音。
   - プロセッサ:ボタンはパラメータではなく、押した回数を音声スレッドに渡す。プロジェクトにキューの状態(cueLifted)を保存し、
     アームが盤の上にあれば、上げた状態・その位置で開く。
   - GUI:UP/DOWN ボタンを START/STOP の上に置いた(下の情報行と重ならないように)。
   - 確認(書き出しツールの cue:START → 9秒 UP → 11秒 Drop point 20%→60% → 20秒 DOWN → 22秒 Drop point 30% → 26秒 UP → 40秒 STOP)
     ・UP から離脱まで約0.5秒(離脱の空気中の音 約 -19dBFS は STOP 時と同じ)。上がりきるのは約1.0秒後。
     ・60% まで 8.3mm/秒で移動し 0.6005 で停止。DOWN から接地まで約1.9秒。再生中に Drop point を動かしても動かず、UP のあとで 30% へ移動(0.2995 で停止)。
     ・移動中のモーターとギアの音は -39〜-50dBFS(アームのカムの回転中と同程度)。キューのモーター停止時のスイッチは約 -37〜-40dBFS。
     ・上げたままの STOP でアームレストに戻る。
     ・既存の書き出しのうち、機械音(arm_down・arm_up・arm_cycles・end_of_side の mechanics)は変更前とビット単位では一致しない。
       差はピークより -200dB 以下で、モーターの減速比を定数から変数にしたことによる浮動小数点の丸め(/fp:fast)の違いだけ。それ以外は一致(scratch_cut は 16. の変更で変わる)。
     ・DustyTableUiCheck にキューの確認を追加(上げる、その場に留まる、Drop point へゆっくり移動して止まる、保存して開き直す、下ろして再生が続く、
       再生中の Drop point の変更では動かず上げたあとで動く、上げたままの STOP、アームレスト上では何もしない)。すべて合格。

18. Drop point を動かしたときに、半透明のアームを表示するようにした(2026-11-24、ユーザーの指示)。
   - ユーザーの依頼:Drop point を動かしたとき、半透明のアームを指定位置に表示する。Drop point が確定したら自動的に消える。
   - 表示:アーム・ヘッドシェル・カウンターウェイトを半透明で描き、ヘッドシェルの縁と針先、着地する溝の円をオレンジ色で薄く示す。本物のアームはその上に描く。
   - 「確定」の扱い:つまみをドラッグしている間は表示し(動かさずに押さえているだけでも表示)、離したら消える(約0.35秒でフェードアウト)。
     ホイール、ダブルクリック、オートメーションなどドラッグ以外で値が変わったときは表示し、約0.8秒変化がなければ確定とみなして消える。
   - DustyTableUiCheck に確認を追加(ドラッグ中は表示、押さえたままでも表示、離すと消える、オートメーションの変更では一時的に表示)。すべて合格。

■ 現在の測定値(オフライン書き出しの数値)
- 接地(カートリッジ経由):約 -6dBFS、低く大きい「ボツッ」(最後の1mm弱を自重で落ちる)
- 離脱(カートリッジ経由):約 -9dBFS
- 空気中の音(ピーク。毎回 ±2〜3dB ほど変わる)
  ・クランプを外す:-30dBFS
  ・クランプを閉める:-21dBFS
  ・START/STOPボタンを押す:約 -27dBFS(2.5kHz付近が中心)
  ・リミットスイッチ:切り欠きから出る -29dBFS、落ちる 約 -37dBFS(200〜600Hz)
  ・モーターとギアの回転中:-42〜-50dBFS
  ・従動レバーが落ちる(下ろすときの「コトッ」):-23dBFS(500〜800Hzと1.3〜1.6kHz)
  ・アームレストのストッパーに当たる:-17dBFS(400〜800Hz)、約0.15秒で -40dBFS まで減衰
- タイミング(0.5秒に Arm を操作した場合)
  ・ダウン:クランプ 0.5秒 → START 1.07秒 → モーター始動 2.07秒 → レバーが落ちる 約4.45秒 → モーター停止 5.50秒 → 接地 約6.2秒
  ・アップ:STOP 0.5秒 → 離脱 1.12秒 → ストッパー 約2.5秒 → レバーが落ちる 約2.8秒 → モーター停止 約3.8秒 → クランプ 約4.6秒
    (モーターの電圧が毎回少し変わるので、時刻は数十ms前後する)
  ・STARTから1秒以内(2.0秒)にSTOPした場合:機構は動かずに、そのままクランプを閉める。
- ホコリ・静電気の書き出しは変更前とビット単位で一致。旧配置のキズは丸め誤差(ピークより -220dB 以下)のみ違う。
